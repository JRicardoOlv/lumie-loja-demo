Nossa história

A Lumiê nasceu da ideia de que maquiagem deve realçar quem você já é, sem esconder nada.

Como tudo começou

Tudo começou com uma pergunta simples: por que é tão difícil achar o tom certo? Queríamos produtos de acabamento leve, cores fáceis de combinar e informações claras para quem está começando.

Esta é uma marca fictícia, criada para este projeto de estudo. Os textos e produtos são exemplos.

O que acreditamos

  • Menos é mais: poucos produtos que funcionam bem juntos.
  • Tons para todas as peles, com descrições honestas.
  • Informação clara, sem promessas exageradas.
